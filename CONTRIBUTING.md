# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a focused branch, for example `feature/accessibility-improvements`.
3. Keep the app dependency-light and mobile-friendly.
4. Run `npm run check` before opening a pull request.
5. Describe the change, how it was tested, and any browser limitations.

Never commit API keys, Telegram tokens, chat IDs, passwords, personal data, or local environment files. Do not add hidden tracking or send browser memory to an external service.
